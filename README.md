# qa_python
# Тестирование метода "add_new_book"
Проверяем корректность добавления 1 книги 
# Тестирование метода "set_book_genre"
Проверяем установление жанра для книги: успешная установка и невалидный жанр (отсутсвующий в списке self.genre), применена параметризация
# Тестирование метода "get_book_genre"
Проверяем по имени книги отсутсвие вывода неустановленного жанра 
# Тестирование метода "get_books_with_specific_genre"
Проверяем вывод имени книги по указанному жанру, применена параметризация
# Тестирование метода "get_books_genre"
Проверяем получение словаря с названиями и жанрами книг
# Тестирование метода "get_books_for_children"
Проверяем вывод названий книг с допустимым для детей жанром 
# Тестирование метода "add_book_in_favorites"
Проверяем добавление книги в избранное
# Тестирование метода "delete_book_from_favorites"
Проверяем удаление книги из избранного
# Тестирование метода "get_list_of_favorites_books"
Проверяем вывод списка избранных книг
